# ExoVision

> Hybrid Quantum-Classical Deep Learning Framework for Exoplanet Detection

ExoVision is a research-oriented framework that explores hybrid quantum-classical deep learning for detecting exoplanets from NASA Kepler stellar light curves. The project combines classical deep learning models with Quantum Neural Networks (QNNs) to investigate whether quantum computing can improve classification performance on noisy astronomical time-series data.

---

## 🎯 Objectives

- Detect exoplanet transit signals from stellar light curves.
- Explore hybrid quantum-classical deep learning architectures.
- Compare classical and quantum-enhanced models.
- Evaluate robustness on noisy astronomical datasets.
- Build a reproducible research framework for Quantum Machine Learning in astrophysics.
